IMPORTANTE: Las reglas anteriores NO permitían leer la config del Drive,
por eso las fotos dejaron de subirse al Drive público.

Esta versión arregla eso + mantiene la corporación funcionando.

PASOS:
1. Firebase Console → tu proyecto → Firestore Database → pestaña "Rules"
2. Reemplazá TODO por esto
3. Publicar

───────────────────────────────────────────────────────────
COPIÁ DESDE ACÁ:
───────────────────────────────────────────────────────────

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Config del Drive público (clientId, secret, refreshToken)
    // Lectura para cualquier usuario logueado (necesario para subir fotos)
    match /config/{doc} {
      allow read: if request.auth != null;
      allow write: if false;  // solo se edita manualmente desde la consola
    }

    // Perfiles públicos (para invitar técnicos por usuario)
    match /publicProfiles/{uid} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == uid;
    }

    // Corporaciones
    match /corporations/{corpId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null
                    && request.resource.data.ownerId == request.auth.uid;
      allow update, delete: if request.auth != null
                    && resource.data.ownerId == request.auth.uid;
      // Un miembro puede salir (quitarse a sí mismo)
      allow update: if request.auth != null
                    && request.auth.uid in resource.data.members
                    && !(request.auth.uid in request.resource.data.members);
    }

    // Datos del usuario (vehículos, sello, imágenes, etc.)
    match /users/{userId}/{document=**} {
      // El dueño: acceso total
      allow read, write: if request.auth != null && request.auth.uid == userId;
      // Otros autenticados: solo lectura (la app filtra por corporación)
      allow read: if request.auth != null;
    }
  }
}

HASTA ACÁ
───────────────────────────────────────────────────────────

El cambio CLAVE para que vuelvan a subir las fotos es el bloque:

    match /config/{doc} {
      allow read: if request.auth != null;
      allow write: if false;
    }

Sin eso, la app no puede leer las credenciales del Drive y por eso
las fotos solo se guardaban en Firestore (base64) pero NO en Drive.
